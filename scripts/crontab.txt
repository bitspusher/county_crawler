# System timezone: America/Los_Angeles (PST/PDT)
#
# ⚠️  DO NOT RUN `crontab scripts/crontab.txt`.
#
#     That REPLACES the whole crontab, and this machine already runs the
#     chess_game_annotator pipeline out of the same crontab. Installing this file
#     wholesale would silently delete those entries.
#
#     This file is a FRAGMENT to append. Install it with:
#
#       crontab -l > /tmp/cron.bak            # back up first, always
#       ( crontab -l; cat scripts/crontab.txt ) | crontab -
#       crontab -l                            # verify BOTH pipelines are present
#
#     Note the PATH line below is commented out for exactly this reason: the
#     existing crontab already sets one, and a second PATH= assignment would
#     override it for every entry that follows. Uncomment it ONLY if this becomes
#     the only pipeline in the crontab.
#
#     To remove just these entries later:
#       crontab -l | grep -v county_crawler | crontab -
#
# ── Cadence ───────────────────────────────────────────────────────────
# Slots: 00,06,12,18 (see scripts/pipeline_id.sh — STRIDE_HOURS=6).
# Entries fire at 03,09,15,21 — deliberately OFFSET from the chess pipeline's
# even-hour slots so the two do not start simultaneously and compete for the
# same rolling Claude quota. Each project has its own .pipeline.lock, so flock
# will NOT serialize them for you; the offset is the only thing that does.
#
# Slot arithmetic: a 03:00 firing computes slot 00, and its fallbacks at 03:30 /
# 04:00 / 04:30 all resolve to slot 00 as well, so the idempotency guards
# correlate them. Same pattern at 09→06, 15→12, 21→18.
#
# 4 cycles/day rather than the chess pipeline's 12, because this repo is ~800
# lines with 23 open roadmap items and a human-gated blocker at its centre. At 12
# cycles/day the roadmap is exhausted in a week and the architect starts
# inventing work — actively harmful on a codebase with no ground truth.
#
# Phases chain sequentially (1→2→3→4); only Phase 1 needs an entry. The fallback
# entries catch a broken chain, and the idempotency guards make them no-ops when
# the chain already completed the phase.
#
# ── Before enabling any of this ────────────────────────────────────────
# The pipeline will happily generate specs against a project whose central
# question is unanswered. Settle it first:
#     python scripts/probe_xhr.py --headed
# Until that returns a verdict, the architect is triaging findings about code
# nobody knows works.

# Cron runs with a minimal PATH. Commented out — see the warning above.
